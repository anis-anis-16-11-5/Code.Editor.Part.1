Code.Editor.Part.1 for Windows

Run Code.Editor.Part.1-Setup-1.0.0.exe and follow the installation wizard. The installer creates Start Menu and Desktop shortcuts with the Code.Editor.Part.1 name and icon.

ZIP projects are saved to your Windows Downloads folder under Code.Editor.Part.1. Windows notifications announce completed downloads. The app keeps the supplied editor UI and its project-upload, preview and ZIP-download features.

This build is unsigned; Windows SmartScreen may show its normal first-run warning. Choose More info > Run anyway only if you trust the source of this installer.
