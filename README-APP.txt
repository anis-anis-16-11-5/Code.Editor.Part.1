Code.Editor.Part.1
==================

النسخة المكتبية: موقع الويب قابل للتثبيت كتطبيق PWA من Chrome أو Edge بعد نشره عبر HTTPS. افتح قائمة المتصفح واختر Install app / تثبيت التطبيق.

نسخة Android: ملف APK يُبنى من مجلد android عبر سير عمل GitHub Actions. نزّل artifact المسمى Code.Editor.Part.1-Android-APK وثبّت app-debug.apk على هاتف Android (قد يطلب الهاتف السماح بالتثبيت من هذا المصدر).

رفع الملفات: اضغط أيقونة الرفع واختر ملف HTML أو ZIP من جهازك.
تنزيل المشروع: من صفحة المعاينة اضغط تنزيل ZIP. في Android يُحفَظ داخل Downloads/Code.Editor.Part.1 وتظهر رسالة نظام بصوت النغمة المرفقة. اسمح بالإشعارات عند أول تشغيل.
